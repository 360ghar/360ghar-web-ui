# 360ghar-web-ui

The 360Ghar website (360ghar.com). Astro 7 with React 19 islands, TypeScript strict, Tailwind v4, TanStack Query, Zustand, openapi-fetch, React Hook Form with Zod. Netlify adapter.

## Setup

- pnpm 12 (`packageManager` in `package.json`) and Node 22.12 or newer. Do not use npm or yarn.
- Copy `.env.example` to `.env`. Variables the browser reads start with `PUBLIC_`.
- `pnpm install --frozen-lockfile`

## Commands

| Command | What it does |
|---|---|
| `pnpm dev` | Dev server on port 4321 |
| `pnpm build` | Production build into `dist/` (also writes the Hindi route tree) |
| `pnpm typecheck` | `astro check` and `tsc` |
| `pnpm lint` | ESLint |
| `pnpm test` | Vitest |
| `pnpm test:e2e` | Playwright, needs the dev server on port 4321 |
| `pnpm check:api` | Fails when `src/lib/api/schema.d.ts` is stale |
| `pnpm check:pseo` | Landing page quality rules |
| `pnpm api:sync && pnpm api:types` | Copy the backend contract and regenerate the API types |

## Rules

1. Run one dev server only. Stop it before `pnpm build`.
2. If Vite dependencies go stale, restart with `pnpm exec astro dev --force`.
3. Do not use `astro preview` to check the Netlify adapter. Use a dev server or the deploy preview.
4. API types come from the backend contract: `openapi/openapi.json` is a copy of `360ghar-backend/docs/openapi.json`. Run `pnpm api:sync && pnpm api:types` after the backend changes, and commit both files. Do not hand-edit `schema.d.ts`.
5. Where the site and the backend disagree, the backend wins. Log gaps in `docs/backend-gaps.md`.
6. Production deploys through Netlify's own git build (`pnpm build`, Node 22, `netlify.toml`) when `main` changes. There is no GitHub deploy workflow.
7. `public/assets/images/` holds old image URLs that search engines and links still use. Keep it.
8. `src/pages/hi/` is generated by `scripts/sync-hi-routes.mjs` and is git-ignored.

## Design

Read the design law in `~/.claude/CLAUDE.md` before any UI change, and `docs/design-system.md` for the Paper Cut Diorama style. Dense screens (account, forms, lists) stay flat and reuse the existing components and tokens. Content must be visible without animation. Respect `prefers-reduced-motion`. Targets are at least 44 px. Meet WCAG 2.2 AA.
