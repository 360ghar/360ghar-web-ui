# 360ghar-web-ui

The 360Ghar website (360ghar.com). Astro 7 with React 19 islands, TypeScript strict, Tailwind v4, TanStack Query, Zustand, openapi-fetch, React Hook Form with Zod. Cloudflare Workers adapter (`@astrojs/cloudflare`, `wrangler.jsonc`); `netlify.toml` stays in the repo as the Netlify rollback reference (the production cutover to the Worker happened 2026-11-03; Netlify no longer serves production).

## Setup

- pnpm 12 (`packageManager` in `package.json`) and Node 22.23.4 or newer (astro 7.4.4's floor; the Workers Builds image's default Node 24 satisfies it, its preinstalled 22.23.2 does not). Do not use npm or yarn.
- Copy `.env.example` to `.env`. Variables the browser reads start with `PUBLIC_`.
- `pnpm install --frozen-lockfile`

## Commands

| Command | What it does |
|---|---|
| `pnpm dev` | Dev server on port 4321 |
| `pnpm build` | Production build into `dist/` (also writes the Hindi route tree) |
| `pnpm typecheck` | `astro check` and `tsc` |
| `pnpm lint` | ESLint |
| `pnpm test` | Vitest |
| `pnpm test:e2e` | Playwright, needs the dev server on port 4321 |
| `pnpm check:api` | Fails when `src/lib/api/schema.d.ts` is stale |
| `pnpm check:pseo` | Landing page quality rules |
| `pnpm api:sync && pnpm api:types` | Copy the backend contract and regenerate the API types |

## Rules

1. Run one dev server only. Stop it before `pnpm build`.
2. If Vite dependencies go stale, restart with `pnpm exec astro dev --force`.
3. Prod-shape local checks: `pnpm build && pnpm preview` (workerd) or `pnpm build && pnpm exec wrangler dev --port 8787`. `astro dev` also runs on workerd since the Cloudflare adapter swap.
4. API types come from the backend contract: `openapi/openapi.json` is a copy of `360ghar-backend/docs/openapi.json`. Run `pnpm api:sync && pnpm api:types` after the backend changes, and commit both files. Do not hand-edit `schema.d.ts`.
5. Where the site and the backend disagree, the backend wins. Log gaps in `docs/backend-gaps.md`.
6. Production pipeline: production `360ghar.com` serves from the Worker custom domain (attached 2026-11-03 to Worker `360ghar-web-ui`, proxy on, domain live within ~90 s). `main` auto-deploys to the Worker via Cloudflare Workers Builds (`npx wrangler deploy`, Node 24 build image) once connected (one-time dashboard step; connection still unconfirmed 2026-11-03 — the API token lacks the Builds scope) — until then, deploys ship via `npx wrangler deploy` with the out-of-repo env token. Netlify no longer serves production: its post-merge publish is broken (404), so the rollback path starts with a Workers version rollback, and restoring Netlify requires re-publishing a known-good deploy from the Netlify dashboard. Runbook: `docs/perf/cloudflare-rollback.md`.
7. `public/assets/images/` holds old image URLs that search engines and links still use. Keep it.
8. `src/pages/hi/` is generated by `scripts/sync-hi-routes.mjs` and is git-ignored.

## Design

Read the design law in `~/.claude/CLAUDE.md` before any UI change, and `docs/design-system.md` for the Paper Cut Diorama style. Dense screens (account, forms, lists) stay flat and reuse the existing components and tokens. Content must be visible without animation. Respect `prefers-reduced-motion`. Targets are at least 44 px. Meet WCAG 2.2 AA.
