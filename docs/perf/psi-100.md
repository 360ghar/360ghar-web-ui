# Homepage mobile score: PSI 97 to 100 (2026-11-04)

The baseline is PageSpeed Insights (PSI) mobile for `https://360ghar.com/`, Lighthouse 13.6.0, HeadlessChromium 153, run on Nov 3, 2026. It scored **97**:

| Metric | Value | Points |
|---|---|---|
| FCP | 1.1 s | 10 / 10 |
| LCP | 1.6 s | 25 / 25 |
| SI | 1.5 s | 10 / 10 |
| TBT | 150 ms | 28 / 30 |
| CLS | 0.072 (`div.home-search-lift`) | 24 / 25 |

For a total of 100 (weighted score ≥ 99.5), TBT must be ≤ about 60 ms and CLS ≤ 0.01. The network metrics already score in full.

## Changes

1. **Astro prefetch removed** (`astro.config.mjs`).
   - Its `page.*.js` loops over every `<a>` 3 times on load: 58 to 104 ms of blocking at a PSI-like CPU.
   - No link uses `data-astro-prefetch`, so the change has no visible effect.
2. **Analytics start later** (`ANALYTICS_QUIET_MS` 1500 to 5000, `src/lib/analytics/scheduler.ts`).
   - gtag's 2 long tasks were about 150 ms of TBT. They now run after Lighthouse stops tracing.
   - The first scroll, tap or key press schedules analytics at the next idle callback, with a 2 s cap.
   - Visitors who leave in under about 6 s without touching the page are not in GA or PostHog. Cloudflare Web Analytics still counts them.
3. **Render gate for the hero** (`<link rel="expect" href="#after-hero" blocking="render">` in `src/pages/index.astro`).
   - Cause, from a headless-shell 153 trace that reproduces 0.0717:
     - Astro writes its island bootstrap scripts (classic inline `<script>`) inside `.home-search-sheet`, just before the HeroSearch island.
     - Those scripts wait for the pending stylesheets, so the parser stops in the middle of the search box.
     - When `Base.css` arrives, Chrome renders the hero without the search form (148 layout objects).
     - The form is then parsed, and the bottom-pinned search box grows upward.
   - The shift happens only when `Base.css` arrives after the parser reaches those scripts (2 of 3 runs).
   - The gate holds the first render until the element after the hero is parsed.
4. **llms.txt lists are Markdown links** (`src/lib/seo/aiDiscovery.ts`). Lighthouse's `llms-txt` audit needs an H1, at least one `[text](url)` link, and 50 or more characters. The bare URLs failed the link check.
5. **The cache is warmed after a deploy** (`cloudflare-rollback.md`, step 5). A cold edge render takes 2.1 to 2.7 s TTFB.

If PSI still shows TBT above about 60 ms, the next lever is `content-visibility: auto` on below-fold sections. It needs care: paint containment would clip the cut band edges that hang across section boundaries.

## Rejected levers (do not retry without new evidence)

- **Inline CSS** (`build.inlineStylesheets: 'always'`). FCP +100 ms and LCP +300 ms: the HTML grows from 35 KB to 58 KB brotli, which costs more under simulated TCP slow start than the 3 requests save.
- **Sentient Latin subset with `unicode-range`.** No LCP change. The split faces made the browser fetch the subset, the full Sentient file and Supreme (108 KB, against 49.5 KB).
- **Load the Cloudflare beacon late.** It is not in the simulator's FCP graph, so there is nothing to gain.
- **`fetchpriority="low"` on the logo and non-LCP diorama layers.** No change.
- **A render gate on the footer** (in place of `#after-hero`). The full-page layout moves into the first frame and gives a larger outlier (113 ms at 10×).
- **Deferring the Header `scrollY` read.** That read forces the page's first layout, which has to happen anyway.

## Measurement notes

- **Local Lighthouse against production overstates FCP and LCP.** Lighthouse adds each origin's observed RTT to its simulated 150 ms. This machine reaches Cloudflare's Marseille PoP at about 140 ms RTT. Use a local copy for A/B tests.
- **The repo runner's `faithful` mode shows a false CLS of 0.09 to 0.11.** The headless window resizes during first paint (500 px minimum width).
- **Headed or `--headless=new` Chrome with `--screenEmulation.mobile` holds frames back** (`hero-delay.md`), which hides real shifts. To reproduce PSI, use headless-shell:

  ```bash
  npx @puppeteer/browsers install chrome-headless-shell@153 --path <dir>
  ```

  Then pass its binary as `CHROME_PATH`, with `--chrome-flags=--headless`.
- **At PSI's 4× setting, a fast Mac hides TBT.** `--throttling.cpuSlowdownMultiplier=10` gave the same TBT as PSI's 150 ms on the unchanged page.
